PUNTUUUU'S LOVE JAR
===================

1. Extract this ZIP file.
2. Open the folder and make sure index.html is visible.
3. Upload index.html to your GitHub repository (the one you created, my-puntuuu).
4. On GitHub, open Settings -> Pages.
5. Under Build and deployment, choose "Deploy from a branch".
6. Choose branch "main" and folder "/ (root)", then Save.
7. Wait a minute or two. GitHub will show your website URL on the Pages screen.
8. Open that URL on your phone to test it, then send the link to Puntuuuu on WhatsApp.

Keep the filename exactly: index.html
